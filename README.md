# Research Methods — Obsidian Course Vault

An Obsidian-compatible knowledge base for the Research Methods course at the University of Hildesheim.

## Open in Obsidian
1. Clone or download this repository.
2. In Obsidian, choose **Open folder as vault** and select the repository folder.
3. Start at [[00 - Course Overview/Course Dashboard]].

## Structure
- `00 - Course Overview`: dashboard, lecture index, study progress.
- `01 - Lectures`: notes, summaries, key concepts, questions.
- `02 - Research Methods`: method reference notes.
- `03 - Fundamental Concepts`: foundational topics.
- `04 - Exercises`: exercise logs and practice questions.
- `05 - Research Papers`: paper summaries and literature review.
- `06 - Exam Preparation`: flashcards, question bank, mock exams, revision.
- `07 - Projects & Assignments`: course deliverables.
- `Attachments`: lecture materials.

Lecture slides and transcripts are the primary sources. Notes will distinguish lecture content from supplementary explanations.
