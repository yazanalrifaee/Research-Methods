# Chapter 2 — Metrics: Summary

## Core idea
Research needs meaningful data. Metrics define what to observe and how to quantify it so results can be interpreted. Metrics are context-specific and should be derived from the purpose of the investigation.

## Fundamentals
- Decide what to observe, the procedure for determining it, and how it is quantified.
- Measurement definitions matter (e.g., different LoC counting conventions).
- Metrics may be objective/subjective, direct/indirect, and product/process/people-oriented.
- Indirect metrics are derived from direct measures (e.g., productivity = size/effort).

## Scale types
| Scale | Meaning | Supported operations | Example |
|---|---|---|---|
| Nominal | Categories, no order | Equality | Defect type |
| Ordinal | Ordered categories | Equality, order | Low/medium/high complexity |
| Interval | Equal meaningful differences | Differences, mean, SD, correlation/regression (as appropriate) | Celsius temperature |
| Ratio | Interval + meaningful zero | Ratios | Duration, mass, count |

Likert responses are ordinal in principle. Treating them as interval requires assumptions about equal spacing and should be done cautiously.

## GQM
Goal → Question → Metric.
- Top-down: refine goal into questions and metrics.
- Bottom-up: interpret measurements to answer questions and evaluate the goal.
- Four phases: Planning → Definition → Data Collection → Interpretation.
- Goal template: object, purpose, quality focus, viewpoint, context.

## Main takeaway
Do not collect metrics simply because they are available. Derive relevant measurements from the goal and questions, and ensure the scale permits the analysis you intend.
